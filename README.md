# symmetrical-funicular

## Оптимизатор маршрута

`index.html` — приложение для построения оптимального маршрута из маршрутного листа Excel.

### Как пользоваться

1. Откройте `index.html` двойным щелчком в браузере (интернет нужен только для шага 4 — определения координат адресов).
2. Загрузите файл Excel (.xlsx) со списком адресов — кнопка со скрепкой.
3. Проверьте / выберите столбец, где находятся адреса. При необходимости добавьте адреса, которых нет в файле, в отдельное поле.
4. Нажмите «Построить маршрут» — приложение определит координаты всех адресов и посчитает наиболее короткий порядок объезда.
5. Нажмите готовую ссылку — откроется маршрут в Яндекс.Картах.

Для города можно задать значение по умолчанию (например, «Москва»), которое добавится к каждому адресу — это повышает точность поиска, если в маршрутном листе город не указан.

Приложение не требует установки, серверов и API-ключей: всё считается прямо в браузере. Координаты адресов определяются через бесплатный сервис геокодирования Nominatim (OpenStreetMap).
